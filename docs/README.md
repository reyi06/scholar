# Documentation

Technical documentation for the Scholar website.

- `spec/SPEC.md` — product scope, routes, data, rules and current status.
- `architecture/ARCHITECTURE.md` — system shape, requests, data, workflows and build.
- `architecture/API.md` — endpoint groups, status codes, pagination and uploads.
- `architecture/DECISIONS.md` — why the stack and the invariants look like this.
- `design/DESIGN.md` — tokens, typography, components, patterns and accessibility.
- `deployment/DEPLOY.md` — environment variables and deployment steps.
- `security/SECURITY-REVIEW.md` — findings, severities and pre-deployment checklist.

Group planning, member task lists and the capstone paper are kept outside this
repository.
